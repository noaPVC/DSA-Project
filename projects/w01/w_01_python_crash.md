# Week 01: Python Crash Course + Arrays & Strings

## Purpose

This week lays the groundwork for all upcoming data structures and algorithmic work. You'll not only review core Python concepts but also dive into two foundational domains — arrays and strings — that underpin much of algorithmic problem solving.

---

## Python Fundamentals (Days 1–4)

### 1. Syntax & Control Structures
- Python indentation rules
- `if/elif/else`, `while`, `for`, `break`, `continue`
- Truthy/falsy values
- Boolean logic, short-circuiting

### 2. Data Types & Structures
- **Primitives**: `int`, `float`, `str`, `bool`, `NoneType`
- **Containers**: 
  - `list` — ordered, mutable
  - `tuple` — ordered, immutable
  - `set` — unordered, unique
  - `dict` — key-value mappings, dynamic

- **Operations**: slicing, indexing, `in`, `len()`, `.append()`, `.pop()`, `.remove()`, `.update()`, `.copy()`

### 3. Functions & Scoping
- Defining and calling functions
- Positional, keyword, default arguments
- Unpacking: `*args`, `**kwargs`
- Return values, multiple returns
- `global`, `nonlocal`, local scope behavior

### 4. Comprehensions
- List, dict, set comprehensions
- Filtering and transformation patterns

### 5. Object-Oriented Python
- Class definitions and `__init__`
- Attributes and instance methods
- `self` and `cls` conventions
- Inheritance and polymorphism
- Dunder methods: `__str__`, `__repr__`, `__eq__`, `__len__`, `__getitem__`

### 6. Modules, Imports, Scripts
- Import styles (`import`, `from ... import`)
- The Python module system
- `__name__ == "__main__"` idiom
- Creating reusable modules

---

## Arrays & Strings (Days 5–6)

### 1. Core Patterns
- **Two pointers**: finding pairs, reversing arrays, in-place edits
- **Sliding window**: substring and subarray analysis
- **Prefix sums**: range queries and cumulative logic
- **Frequency maps**: character counting and grouping
- **Set membership**: uniqueness checks

### 2. Arrays (Lists)
- Common mutations: insert, delete, replace
- Slicing with step (`[::2]`), negative indexing
- Sorting strategies
- Edge cases: empty arrays, single element, large `k`

### 3. Strings
- Immutability of strings
- Slicing, concatenation, `.join()`, `.split()`
- Checking prefixes/suffixes
- Building efficient strings with `''.join()`
